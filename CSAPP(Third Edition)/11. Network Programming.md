# 11.1 The Client-Server Programming Model

- 网络应用均基于 客户-服务器 模型
- 一个应用由一个服务器进程和一个或多个客户端进程组成
- 服务器管理某种资源，通过操作这种资源为客户端提供某种服务 
- 模型的基本操作是事务(transaction):

	1. 客户端需要服务，向服务器发送请求，发起事务
	2. 服务器收到请求，解释请求，操作资源
	3. 服务器给客户端发送响应，等待下一个请求
	4. 客户端收到响应并处理

- 客户端、服务器是进程，而非机器或主机
	- 一台主机可同时运行不同的客户端、服务器
	- 客户端、服务器的事务可在同一/不同主机上
	- 无论客户端、服务器如何映射到主机，客户端-服务器模型相同

**客户端服务器事务并非数据库事务，没有数据库事务的任何特性**

# 11.2 Networks

- 对主机而言，网络只是IO设备，是数据源和数据接收方
- 物理上，网络是按照地理远近组成的层次系统
	- 最低层LAN(Local Area Network 局域网)
	- 更高级别，多个不兼容的局域网通过路由器(router)连接，组成internet
	- 路由器也能连接高速点到点电话连接，WAN(Wide-Area Network 广域网)

**重要特性：能采用完全不同和不兼容技术的各种局域网和广域网组成**

- 协议软件消除不同网络之间的差异，控制主机和路由器协同工作来实现数据传输，提供命名机制和传送机制
	- 命名机制：不同局域网有不同和不兼容的方式为主机分配地址，IP协议通过定义一致的主机地址格式消除差异，每台主机会被分配至少一个互联网络地址(internet address)，这个地址唯一标识了这台主机
	- 传送机制：在电缆上编码位和将位封装成帧方面，不同的联网技术有不同和不兼容的方式，TCP协议通过定义把数据位捆扎成不连续的片(包)的统一方式消除差异。一个包有包头和有效载荷组成，包头包括包的大小和源主机和目的主机地址，有效载荷包括从源主机发出的数据位

# 11.3 The Global IP Internet

- 每台因特网主机都运行实现TCP/IP协议(Transmision Control Protocol/Internet Protocol)的软件
- 客户端和服务器混合使用套接字接口函数和Unix IO函数进行通信
- TCP/IP是一个协议族
	- IP协议提供基本的命名方法和递送机制，递送机制从一台主机往其他主机发送数据报(datagram)
	- IP机制不可靠，因为数据报在网络中丢失或者重复并不会试图恢复，UDP(Unreliable Datagram Protocol，不可靠数据报协议)扩展了IP协议，包可以在进程间而非主机间传送
	- TCP是一个构建在IP之上的协议，提供进程间可靠的全双工(双向)连接
- 因特网可以看作一个世界范围的主机集合，满足特性：
	- 主机集合被映射为一组32位的IP地址
	- IP地址被映射为因特网域名(Internet domain name)标识符
	- 因特网主机上的进程能够通过连接(connection)和任何其他因特网主机上的进程通信

## 11.3.1 IP Addresses

- 一个IP地址就是一个32位无符号整数
- 因特网主机有不同的主机字节顺序，TCP/IP为任意整数数据项定义了统一的网络字节顺序(network byte order)(大端字节顺序)
- IP地址以点分十进制表示法来表示，每个字节由它的十进制表示，用句点和其他字节区分开
